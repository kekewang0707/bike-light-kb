**目标**：封装 ChromaDB 操作，提供统一的语义查询接口。上层应用不直接操作向量数据库。

**依赖**：M1（数据模型层）、M3（评价分析）、M4（图片分析）

## 2. ChromaDB Collection 设计

| Collection 名称 | 用途 | 维度 | 元数据字段 |
|:---|:---|:---|:---|
| `selling_points` | 卖点描述向量 | 1024 | product_id, review_id, aspect, mention_count |
| `use_scenes` | 使用场景向量 | 1024 | product_id, review_id, scene, confidence |
| `pain_points` | 痛点描述向量 | 1024 | product_id, review_id, aspect, severity |
| `product_descriptions` | 商品综合描述向量 | 1024 | product_id, name, brand, price_range |
| `image_descriptions` | 图片语义描述向量 | 1024 | product_id, image_id, image_type, style_tags |
| `image_clip` | CLIP 图片向量 | 512 | product_id, image_id, local_path |

class ChromaClientManager:
    """ChromaDB 客户端管理"""

### 3.4 QueryService (query_service.py)

```python
class QueryService:
    """语义查询服务"""

    async def semantic_search(
        self, query: str, collection_name: str,
        top_k: int = 20, where: dict = None
    ) -> List[SearchResult]:
        """基础语义搜索: query → embedding → ChromaDB.query"""

    async def cross_collection_search(
        self, query: str, collections: List[str],
        top_k_per: int = 10
    ) -> List[SearchResult]:
        """跨 Collection 搜索，合并去重"""

    async def search_selling_points(
        self, query: str, top_k: int = 20
    ) -> List[SearchResult]:
        """搜索卖点"""

    async def search_scenes(
        self, query: str, top_k: int = 20
    ) -> List[SearchResult]:
        """搜索使用场景"""

    async def search_pain_points(
        self, query: str, top_k: int = 20
    ) -> List[SearchResult]:
        """搜索痛点"""

    async def hybrid_search(
        self, query: str, top_k: int = 20
    ) -> List[SearchResult]:
        """混合搜索：同时搜卖点+场景+商品描述，去重合并"""

    async def search_images(
        self, query: str, top_k: int = 10
    ) -> List[SearchResult]:
        """文本搜图片描述"""

    async def search_similar_images(
        self, image_vector: np.ndarray, top_k: int = 10
    ) -> List[SearchResult]:
        """CLIP 以图搜图"""

    async def get_product_knowledge(
        self, product_id: int
    ) -> ProductKnowledge:
        """获取单商品知识卡片"""

    async def get_category_insights(self) -> CategoryInsights:
        """品类洞察：高频卖点/场景/痛点统计"""
```

### 3.5 KnowledgeBase 门面 (__init__.py)

```python
class KnowledgeBase:
    """知识库门面 — 应用层的唯一入口"""

    def __init__(self):
        self.chroma = ChromaClientManager()
        self.store = VectorStore()
        self.query = QueryService()

    # ---- 写入 ----
    def index_reviews(self, analyses: List[ReviewAnalysis]):
        """将评价分析写入卖点/场景/痛点 Collection"""
        self.store.index_selling_points(analyses)
        self.store.index_use_scenes(analyses)
        self.store.index_pain_points(analyses)

    def index_products(self, products: List[Product]):
        """商品信息写入 product_descriptions"""
        self.store.index_products(products)

    def index_images(self, analyses: List[ImageAnalysis]):
        """图片分析写入 image_descriptions + image_clip"""
        self.store.index_image_descriptions(analyses)

    # ---- 查询(委托给 QueryService) ----
    async def search(self, query: str, scope: str = "all", top_k: int = 20):
        """
        统一查询入口。
        scope: "selling_points" | "scenes" | "pain_points" |
                "products" | "images" | "hybrid" | "all"
        """

    async def get_insights(self, product_id: int = None) -> dict:
        """获取洞察：指定商品或全品类"""
```

| 步骤 | 内容 | 产出 |

## 6. 关键设计决策

- **门面模式**：KnowledgeBase 是应用层唯一入口，隐藏 ChromaDB 细节，方便后期切换 Milvus
- **先 OpenAI embedding，后本地部署**：初期用 `text-embedding-3-small` 快速上线，数据量大后再切换 `bge-large-zh-v1.5` 本地部署以节省成本
- **向量双写**：评价分析结果同时存 PostgreSQL（精确查询+统计）+ ChromaDB（语义搜索）
- **跨 Collection 混合检索**：一次查询同时搜索多个 Collection，合并去重后按商品聚合，提供更全面的结果
- **ChromaDB 初期够用**：< 10000 向量时 ChromaDB 性能完全满足，Phase 4 再评估是否迁移到 Milvus
