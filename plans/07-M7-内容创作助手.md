# M7 — 内容创作助手

**目标**：文案同学输入商品/品类，自动输出卖点洞察、竞品参考、AI 生成的标题和详情页框架。

**依赖**：M1（数据模型层）、M5（知识库服务层）

**目录**：`ui/creator/`

---


**Prompt 设计**：

```python
SYSTEM_PROMPT = """你是自行车灯品类的电商文案专家。你的文案：
1. 基于真实用户评价中的卖点（确保言之有物）
2. 用数据说话（流明、续航小时数、防水等级）
3. 场景化表达（通勤/夜骑/长途）
4. 符合电商 SEO 标题规范（品牌+核心词+属性词+场景词，50字以内）
5. 突出差异化（如果竞品都在说"亮"，我们就说"亮的久"）
"""

TITLE_PROMPT = """基于以下信息，生成 5 个电商标题：
目标人群: {target_audience}
价格定位: {price_range}
核心卖点: {selling_points}     （来自真实评价，按提及率排序）
使用场景: {use_scenes}          （来自真实评价）
竞品标题: {competitor_titles}   （Top10 商品标题）

要求：50字以内，包含 1-2 个核心参数 + 1 个场景词，有差异化角度。
"""

DETAIL_PROMPT = """生成详情页内容框架：
1. 核心卖点（3-5 个，每个配数据支撑）
2. 使用场景（2-3 个，配场景描述）
3. 规格参数表（markdown 表格）
4. 对比优势（与同价位竞品比）
"""
```

**知识库增强**：调用 `KnowledgeBase.hybrid_search()` 获取相关卖点、场景、竞品信息作为 Prompt 上下文。

## 4. 关键设计决策

- **知识库是文案质量的保障**：所有 AI 生成的文案必须以 ChromaDB 中的真实评价数据为上下文，确保"言之有物"
- **AI 生成 + 人工优化**：文案生成是辅助工具，提供的是"初稿"和"灵感"，最终需要人工优化
- **Prompt 模板化**：标题/详情框架 Prompt 存为模板，便于后期根据文案同学反馈迭代优化
- **LLM 调用加缓存**：相同参数（人群+价位+风格）的生成结果可短期缓存，避免重复调用
- **评价原文引用**：场景展示和卖点详情中始终保留用户原话，增加可信度
