# M4 — 图片分析管道

**目标**：对商品图片进行 OCR 文字提取、多模态描述生成、CLIP 向量化，让图片可被语义检索。

**依赖**：M1（数据模型层）

**目录**：`analysis/image/`

---

```
analysis/image/
```

## 2. 核心类设计

### 2.1 OCRExtractor (ocr.py)

```python
class OCRExtractor:
    """商品图片 OCR 文字提取"""

    def __init__(self, lang: str = "ch"):
        """初始化 PaddleOCR（懒加载，首次使用时加载模型）"""

    def extract(self, image_path: str) -> OCRResult:
        """
        提取单张图片文字。
        返回: OCRResult(full_text, text_blocks, key_phrases)
        """

    def extract_batch(self, image_paths: List[str]) -> List[OCRResult]:
        """批量 OCR，顺序处理"""

@dataclass
class OCRResult:
    full_text: str                 # 所有识别文本
    text_blocks: List[dict]         # [{"text":"800流明亮","bbox":[...],"confidence":0.95}]
    key_phrases: List[str]          # 可能是卖点标签的文字块，如["800流明","IPX6防水"]
```

### 2.3 CLIPVectorizer (clip_vectorizer.py)

```python
class CLIPVectorizer:
    """CLIP 图片向量化 + 风格聚类"""

    def __init__(self, model_name: str = "ViT-B/32"):
        """加载 OpenAI CLIP 模型。默认用最小模型 ViT-B/32。"""

    def vectorize(self, image_path: str) -> np.ndarray:
        """生成 512维 CLIP 向量"""

    def vectorize_batch(self, image_paths: List[str]) -> np.ndarray:
        """批量向量化，shape (N, 512)"""

    def save_to_chromadb(
        self, product_id: int, image_id: int,
        vector: np.ndarray, chroma_client
    ):
        """将 CLIP 向量存入 ChromaDB image_clip collection"""

    def cluster_styles(
        self, vectors: np.ndarray, n_clusters: int = 5
    ) -> StyleClusters:
        """K-Means 聚类，返回每个簇的代表图和风格关键词"""

    def find_similar(
        self, image_path: str, chroma_client, top_k: int = 10
    ) -> List[SimilarImage]:
        """以图搜图：在 ChromaDB 中搜索最相似的图片"""

@dataclass
class StyleClusters:
    n_clusters: int
    clusters: List[StyleCluster]  # 每个簇: {images, top_style_tags, count}

@dataclass
class SimilarImage:
    image_id: int
    product_id: int
    local_path: str
    similarity: float
```

## 3. 图片分析流水线

```python
class ImageAnalysisPipeline:
    """端到端图片分析流水线"""

    def __init__(self):
        self.ocr = OCRExtractor()
        self.describer = MultimodalDescriber()
        self.clip = CLIPVectorizer()

    async def analyze_all(
        self, images: List[ProductImage], db_session: Session
    ) -> ImageAnalysisReport:
        """
        对全部商品图片执行分析：
        step1: OCR 提取文字 → 写入 image_analysis.ocr_text
        step2: 多模态描述(仅主图) → 写入 image_analysis.description
        step3: CLIP 向量化 → 写入 image_analysis.clip_vector_id → ChromaDB
        step4: 全品类 CLIP 聚类 → 生成风格分析报告
        """

    async def analyze_single(
        self, image: ProductImage, db_session: Session
    ) -> ImageAnalysis:
        """分析单张图片"""

    async def recluster(self) -> StyleClusters:
        """重新聚类（新图片入库后调用）"""
```

**执行策略**：
- 主图：OCR + 多模态描述 + CLIP 向量化（全量分析）
- 详情图：仅 OCR（提取文字标注即可）
- 评价晒图：跳过分析（Phase 4 可选）

---

## 5. 关键设计决策

- **仅主图做多模态描述**：详情图和评价晒图数量大且信息密度低，只做 OCR 提取文字
- **ViT-B/32 最小 CLIP 模型**：初期图片量 < 1000 张，CPU 亦可接受。后期数据量大可升级到 ViT-L/14 + GPU
- **PaddleOCR 中文优化**：PaddleOCR 在中文场景准确率优于 Tesseract 和 EasyOCR
- **懒加载模型**：OCR/CLIP/VL 模型在首次使用时加载，避免启动时占用大量内存
- **结果双写**：分析结果同时写入 PostgreSQL（结构化查询）和 ChromaDB（语义搜索）
