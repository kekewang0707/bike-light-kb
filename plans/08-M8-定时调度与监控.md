## 2. 核心设计

### 2.1 定时任务 (jobs.py)

```python
class ScheduledJobs:
    """定时任务集合"""

    @staticmethod
    async def crawl_daily():
        """
        每日爬虫任务 - 凌晨2点执行
        采集最新商品数据、评价、热榜
        """
        engine = CrawlerEngine()
        report = await engine.run(
            keywords=["自行车灯", "自行车前灯", "自行车尾灯"],
            max_products=100
        )
        # 记录报告到日志
        # 如有严重异常(成功率<50%)，触发告警

    @staticmethod
    async def update_price_history():
        """
        每日价格快照 - 凌晨3点执行
        对所有活跃商品记录当日价格到 price_history 表
        """

    @staticmethod
    async def check_data_freshness():
        """
        数据新鲜度检查 - 早8点执行
        检查最后爬虫执行时间、各表记录数是否正常
        异常则发送告警
        """

    @staticmethod
    async def generate_daily_report():
        """
        生成每日选品日报 - 早9点执行
        调用 LLM 生成日报摘要:
        - 新上榜商品
        - 价格变动>20%的商品
        - 近期高频好评/差评关键词
        - 今日选品建议
        """
```

**定时任务表**：

| 任务 | 时间 | Cron | 说明 |
|:---|:---|:---|:---|
| crawl_daily | 02:00 | `0 2 * * *` | 每日爬虫数据采集 |
| update_price_history | 03:00 | `0 3 * * *` | 每日价格快照 |
| check_data_freshness | 08:00 | `0 8 * * *` | 数据健康检查 |
| generate_daily_report | 09:00 | `0 9 * * *` | 生成日报摘要 |

### 2.2 调度器配置 (scheduler_app.py)

```python
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from apscheduler.triggers.cron import CronTrigger

def create_scheduler() -> AsyncIOScheduler:
    scheduler = AsyncIOScheduler(timezone="Asia/Shanghai")

    # 注册任务
    scheduler.add_job(
        ScheduledJobs.crawl_daily,
        trigger=CronTrigger(hour=2, minute=0),
        id="crawl_daily",
        max_instances=1,
        coalesce=True           # 如果上次没跑完，跳过本次
    )

    scheduler.add_job(
        ScheduledJobs.update_price_history,
        trigger=CronTrigger(hour=3, minute=0),
        id="update_price_history",
    )

    scheduler.add_job(
        ScheduledJobs.check_data_freshness,
        trigger=CronTrigger(hour=8, minute=0),
        id="check_data_freshness",
    )

    scheduler.add_job(
        ScheduledJobs.generate_daily_report,
        trigger=CronTrigger(hour=9, minute=0),
        id="generate_daily_report",
    )

    return scheduler

def start_scheduler():
    """启动调度器（嵌入 Streamlit 或独立进程）"""
    scheduler = create_scheduler()
    scheduler.start()
    return scheduler
```

### 2.3 数据监控 (monitor.py)

```python
class DataMonitor:
    """数据质量监控"""

    def check_crawl_health(self) -> HealthReport:
        """
        检查项：
        - 最近24h是否有新商品入库
        - 爬虫错误率是否<20%
        - 图片下载成功率是否>80%
        """

    def check_db_size(self) -> SizeReport:
        """
        检查项：
        - 各表记录数
        - 增长速度是否异常(突然翻倍或归零)
        """

    def check_price_anomalies(self) -> List[Anomaly]:
        """
        检查项：
        - 单日价格涨跌>30%
        - 价格倒挂（售价比原价还高）
        """

    def check_analysis_completeness(self) -> CompletenessReport:
        """
        检查项：
        - 评价分析覆盖率 = 已分析评价数 / 总评价数
        - 图片分析覆盖率 = 已分析图片数 / 总图片数
        - 覆盖率<80% 发出提醒
        """

@dataclass
class HealthReport:
    healthy: bool
    checks: List[dict]        # [{name, passed, message}]
    last_crawl_time: datetime
    error_rate: float

@dataclass
class Anomaly:
    product_id: int
    product_name: str
    anomaly_type: str          # "price_spike" | "price_inversion" | ...
    detail: str
    detected_at: datetime
```

## 4. 部署方式

**方案一：嵌入 Streamlit（推荐初期）**
```python
# app.py 启动时同时启动调度器
if __name__ == "__main__":
    scheduler = start_scheduler()
    # ... Streamlit 页面
```

**方案二：独立进程（推荐后期）**
```bash
# 单独运行调度器
python -m scheduler.scheduler_app
```

初期数据量小，方案一足够。后期爬虫任务变重后切换方案二。

## 6. 关键设计决策

- **APScheduler + AsyncIO**：与爬虫引擎（asyncio）一致的异步模型
- **时区用 Asia/Shanghai**：Cron 表达式基于北京时间
- **coalesce=True**：如果上次任务没跑完，跳过本次执行，避免任务堆积
- **先日志后通知**：所有告警同时写 loguru 日志 + 推送钉钉，便于追溯
- **不引入 Celery**：当前任务量少（每天 4 个），APScheduler 足够。后期如果有复杂 DAG 需求再考虑
