# M6 — 选品决策看板

**目标**：运营人员每天打开即看品类全局、价格趋势、市场机会。一个 Streamlit 多页面应用。

**依赖**：M1（数据模型层）、M5（知识库服务层）

**目录**：`ui/dashboard/`

## 2. 页面设计

### 2.1 品类总览 (overview.py)

```
┌──────────────────────────────────────────────────────────┐
│  🚲 自行车灯 · 品类总览                     最后更新: xxx │
├──────────┬──────────┬──────────┬──────────┬──────────────┤
│ 商品总数  │ 均价     │ 月销量   │ 有图商品  │ 已分析评价    │
│   158    │  ¥89.5   │  12,340  │  142     │  2,100 条    │
├──────────┴──────────┴──────────┴──────────┴──────────────┤
│                                                          │
│  📊 价格带分布（柱状图）        🔥 热销 Top20（表格）       │
│                                                          │
│  🏷️ 品牌分布（饼图）           ⭐ 评分分布（直方图）        │
└──────────────────────────────────────────────────────────┘
```

**数据接口（Streamlit 内部直接调 DB/KB）**：
- 概览卡片：`SELECT COUNT(*), AVG(price), SUM(sales_volume)...`
- 价格带分布：按 `price` 分段 GROUP BY
- 热销Top20：`SELECT ... ORDER BY sales_volume DESC LIMIT 20`
- 品牌分布：`SELECT brand, COUNT(*) ... GROUP BY brand`
- 评分分布：`SELECT good_rate ...` 分段统计

### 2.2 趋势分析 (trends.py)

```
┌──────────────────────────────────────────────────────────┐
│  📈 趋势分析                                周期: [周] [月]│
├──────────────────────────────────────────────────────────┤
│                                                          │
│  销量趋势（折线图，支持按价格段筛选）                       │
│  价格趋势（多条折线：均价/中位数/最低价/最高价）             │
│  新晋爆品（近7天上榜 + 增速 > 30%）                        │
│  ┌──────────────────────────────────────────────┐        │
│  │ 商品名          | 上榜日   | 增长%  | 当前排名 │        │
│  └──────────────────────────────────────────────┘        │
└──────────────────────────────────────────────────────────┘
```

**数据来源**：
- 销量/价格趋势：`price_history` 表 + `hot_rankings` 表按日期聚合
- 新晋爆品：对比最近两次 hot_rankings 快照，筛选新增且增速>30%

## 5. 关键设计决策

- **纯 Streamlit 实现**：不需要前后端分离，数据查询直接在同进程内通过 SQLAlchemy 和 KnowledgeBase 完成
- **@st.cache_data 缓存**：图表数据查询默认缓存 5 分钟，减少 DB 压力
- **数据预聚合优先**：优先展示预计算好的聚合数据（`review_analysis` 中的 JSONB 已按商品聚合），避免实时全表扫描
- **AI 建议可选刷新**：机会洞察页面的 AI 建议不每次刷新，提供"重新分析"按钮手动触发（避免 LLM 成本）
- **移动端适配**：Streamlit 默认响应式布局，但自行车灯看板主要在桌面端使用，宽度设置 `layout="wide"`
